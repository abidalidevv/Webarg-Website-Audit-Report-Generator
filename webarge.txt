# 71. Customer Journey Audit

Mandatory high-value journeys:

## Journey A — New visitor
`Search → Homepage → Understand offer → CTA`

`Homepage → Contact → Form → Confirmation → Actual delivery`

`Mobile → Service/Product → Call/WhatsApp → Conversion`

## Journey D — Returning user
`Direct URL → Login → Action → Logout`

## Journey E — Failure recovery
`Wrong input/payment/network error → Retry → Success`

For each:
- PASS
- WARNING

# 73. Finding Quality Rules

Bad finding:

> Website is slow.

Good finding:

> **High — Homepage LCP exceeds target**
>
> Evidence: LCP measured at 4.1s on mobile test.
>
> Impact: Primary content takes longer to become visible.
>
> Recommendation: Optimize hero image delivery and reduce render-blocking resources.
>
> Verification: Re-run mobile performance test after deployment.
