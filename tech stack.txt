Tech stack (final):

Layer	Choice
Frontend	React — single scrolling page, no dashboard sidebar
Backend	Node.js + Express — one /scan endpoint
Scan engine	Browserless.io (hosted headless Chrome)
Analysis	Lighthouse (programmatic) + axe-core + Cheerio + node ssl-checker
PDF	Headless browser's own page.pdf() on the report's URL — not html2canvas/jsPDF
Storage	Flat JSON / lightweight doc store keyed by report ID
Admin	Single password-gated route, env credential — no Firebase, no multi-user
Hosting	Frontend on Vercel/Netlify, small Express server on Railway/Render
